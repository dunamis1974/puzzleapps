# Requirements: PuzzleApps CMS Docker Deployment (v2.0)

**Defined:** 2026-10-28
**Core Value:** Keep the existing CMS usable on a supported PHP runtime while removing obsolete database dependencies without changing its essential workflows.

## v2.0 Requirements

### Runtime Image

- [x] **RUN-01**: A Dockerfile builds a PHP 8.5 php-fpm image with pdo_pgsql, xsl, gd, mbstring, SimpleXML and zlib support that the CMS and installer preflight require.
- [x] **RUN-02**: The image creates the writable runtime directories (files, log, tmp, config, editor cache and temp paths) owned by the PHP-FPM user without world-writable permissions.
- [x] **RUN-03**: A .dockerignore keeps .git, .planning, .env files, logs and runtime data out of the build context.

### Environment Configuration

- [x] **ENV-01**: The database configuration reads engine, host, port, name, user and password from environment variables when they are set, producing the same `$PDO_DATABASE` array the installer writes.
- [x] **ENV-02**: Precedence between environment variables and an installer-written config file is defined and incomplete environment settings produce an explicit DatabaseException.
- [x] **ENV-03**: Installer step 3 detects environment-provided database settings and skips asking for them while still creating the schema.

### Compose Stack

- [x] **CMP-01**: docker-compose.yml defines app (php-fpm), nginx and PostgreSQL 18 services on a private network; PostgreSQL is not published to the host by default.
- [x] **CMP-02**: Named volumes persist PostgreSQL data (/var/lib/postgresql), uploads, logs and generated configuration.
- [x] **CMP-03**: A pg_isready healthcheck gates app start through depends_on service_healthy.
- [x] **CMP-04**: A committed .env.example documents every variable the stack needs; no secrets are committed.

### Web Server

- [x] **NGX-01**: Nginx and php-fpm share the same document root path and pass the FastCGI parameters the CMS uses to build paths.
- [x] **NGX-02**: Nginx reproduces the .htaccess rewrites for .html pages, /gallery/ and /media routes and serves real files first.
- [x] **NGX-03**: Nginx only forwards existing PHP scripts and documents how to restrict /install/ after setup.

### Documentation and Verification

- [x] **DOC-01**: Documentation covers first deploy, installer walkthrough, volumes, backup, upgrade and secrets handling.
- [x] **VER-01**: Dockerfile, compose, nginx config and PHP changes are checked statically (php -l on PHP 8.5, compose and nginx config review); container execution is deferred to the user.

## Out of Scope

- MySQL and SQLite services in compose — PostgreSQL only for this milestone.
- Running or testing containers during the milestone — static checks only.
- Kubernetes, CI/CD pipelines and TLS termination.

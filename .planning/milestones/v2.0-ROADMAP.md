# Roadmap: PuzzleApps CMS Docker Deployment

## Milestones

- ✅ **v1.0 PHP 8.5 and PDO Modernization** — Phases 1-4 (shipped 2026-10-28; archive in `.planning/milestones/1.0-ROADMAP.md`)
- 🚧 **v2.0 Docker Deployment** — Phases 5-8 (in progress)

## Overview

Containerize the CMS in dependency order: a PHP 8.5 runtime image with env-driven database configuration, a compose stack with PostgreSQL and durable state, nginx routing plus installer onboarding, then documentation and static verification. Validation is static only; the user runs containers after the milestone.

## Phase Details

### Phase 5: Runtime Image and Environment Configuration

**Goal**: A PHP 8.5 php-fpm image contains everything the CMS needs and the database configuration can come from environment variables.
**Depends on**: Nothing (first phase of milestone)
**Requirements**: RUN-01, RUN-02, RUN-03, ENV-01, ENV-02, ENV-03
**Success Criteria** (what must be TRUE):
  1. The Dockerfile installs pdo_pgsql, xsl, gd, mbstring, SimpleXML and zlib and sets up writable directories for the FPM user.
  2. .dockerignore excludes .git, .planning, env files and runtime data.
  3. Environment variables produce the same `$PDO_DATABASE` array as the installer; precedence is defined and incomplete settings fail with DatabaseException.
  4. Installer step 3 uses environment-provided settings and still creates the schema.
  5. Changed PHP files lint clean on PHP 8.5.

### Phase 6: Compose Stack and Durable State

**Goal**: One command starts app, nginx and PostgreSQL with persistent state.
**Depends on**: Phase 5
**Requirements**: CMP-01, CMP-02, CMP-03, CMP-04
**Success Criteria** (what must be TRUE):
  1. docker-compose.yml defines the three services on a private network with PostgreSQL unpublished.
  2. Named volumes persist database, uploads, logs and generated configuration.
  3. The app waits for a healthy database.
  4. .env.example documents all variables and no secrets are committed.

**Plans:** 2/2 plans complete

### Phase 7: Nginx Routing and Installer Onboarding

**Goal**: Nginx serves the CMS with the same URL behavior as the Apache rewrites and a safe installer path.
**Depends on**: Phase 6
**Requirements**: NGX-01, NGX-02, NGX-03
**Success Criteria** (what must be TRUE):
  1. Nginx and php-fpm use the same document root and FastCGI parameters.
  2. .html, /gallery/ and /media routes match the .htaccess behavior.
  3. Only existing PHP scripts are forwarded; /install/ restriction after setup is documented or configurable.

**Plans:** 1 plan

**Goal**: The deployment is documented and statically verified with a handoff for container testing.
